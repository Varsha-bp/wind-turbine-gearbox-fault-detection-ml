# wind-turbine-gearbox-fault-detection-ml
ML-based system for detecting gearbox faults in wind turbines using vibration signal analysis and predictive modeling.
## 📌 Overview
This project focuses on detecting gearbox faults in wind turbines using vibration data and machine learning techniques. The system helps in early fault detection, reducing maintenance cost and preventing failures.

## 🚀 Features
- Vibration data preprocessing
- Feature extraction (RMS, FFT, statistical features)
- Machine learning models for fault detection
- Fault classification (normal vs faulty conditions)
- Visualization and analysis dashboard

## 🛠️ Tech Stack
- Python
- NumPy, Pandas
- Scikit-learn
- Matplotlib

## ⚙️ Workflow
1. Data Collection (Vibration signals)
2. Data Preprocessing
3. Feature Extraction
4. Model Training
5. Fault Detection

## 📊 Machine Learning Models Used
- Support Vector Machine (SVM)
- Random Forest
- Logistic Regression

## 📈 Results
Achieved accurate classification of gearbox faults using vibration signal features.

## 🔮 Future Improvements
- Deep Learning (CNN/LSTM)

- IoT-based sensor integration
